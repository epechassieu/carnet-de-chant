# Carnet de Chants 📖

Application Android de gestion de cantiques pour églises protestantes.

## 📚 Documentation

La documentation complète se trouve ici: [carnet-de-chant.readthedocs.io](https://epechassieu.github.io/carnet-de-chant/docs/)

## 🚀 Démarrage rapide
```bash
git clone https://github.com/epechassieu/carnet-de-chants.git
cd carnet-de-chants/app
./gradlew build
```

## 🏗️ Architecture

- **UI**: Jetpack Compose
- **Database**: Room
- **DI**: Hilt
- **Audio**: Media3
- **Networking**: Ktor

Voir [docs/architecture/](docs/architecture/) pour détails.
